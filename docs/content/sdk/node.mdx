# Node: `@0gzk/sdk/node`

This subpath is **Node only**. It uses **`node:fs`**, **`node:path`**, **`tar`**, **`@0gfoundation/0g-ts-sdk`**, and **`ethers`** to read bundles off disk and to talk to **0G Storage**. Do not import it from browser code.

See **[Reference](/reference)** for the shapes of **`BundleFiles`**, **`UploadStage`**, **`UploadProgress`**, **`UploadResult`**, and **`UploadTimeoutError`**.

## Configuration

### `Network`, `NetworkPreset`, `NETWORKS`

```typescript
type Network = "testnet" | "mainnet";

interface NetworkPreset {
  rpcUrl: string;
  indexerUrl: string;
  chainId: number;
  explorer: string;
}

const NETWORKS: Record<Network, NetworkPreset>;
```

Baked-in presets:

| Network | `chainId` | `rpcUrl` | `indexerUrl` | `explorer` |
| --- | ---: | --- | --- | --- |
| **`testnet`** | **`16602`** | **`https://evmrpc-testnet.0g.ai`** | **`https://indexer-storage-testnet-turbo.0g.ai`** | **`https://chainscan-galileo.0g.ai`** |
| **`mainnet`** | **`16661`** | **`https://evmrpc.0g.ai`** | **`https://indexer-storage-turbo.0g.ai`** | **`https://chainscan.0g.ai`** |

### `StorageConfig`

```typescript
interface StorageConfig {
  network: Network;
  rpcUrl: string;
  indexerUrl: string;
  chainId: number;
  explorer: string;
  privateKey?: string;
}
```

The full config object. Every function in this module either takes a **`StorageConfig`** or a subset of it (**`fetchBundle`** only needs **`indexerUrl`**, for instance).

### `loadConfig`

```typescript
function loadConfig(overrides?: Partial<StorageConfig>): StorageConfig;
```

Merges **`overrides`** with environment variables, falling back to network presets. The resolution order for each field is **override -> env -> preset**.

| Field | Env var | Default |
| --- | --- | --- |
| **`network`** | **`OG_NETWORK`** (must be exactly **`testnet`** or **`mainnet`**) | **`mainnet`** |
| **`rpcUrl`** | **`OG_RPC_URL`** | preset RPC for **`network`** |
| **`indexerUrl`** | **`OG_INDEXER_URL`** | preset indexer for **`network`** |
| **`privateKey`** | **`OG_PRIVATE_KEY`** | **`undefined`** |
| **`chainId`** | (not read from env) | preset **`chainId`** |
| **`explorer`** | (not read from env) | preset **`explorer`** |

```typescript
import { loadConfig } from "@0gzk/sdk/node";

const config = loadConfig();                      // env-only
const testnet = loadConfig({ network: "testnet" }); // force testnet
const explicit = loadConfig({
  rpcUrl: "https://my-private-rpc.example",
  privateKey: process.env.MY_KEY,
});
```

### `requireSigningConfig`

```typescript
function requireSigningConfig(
  config: StorageConfig,
): asserts config is StorageConfig & { privateKey: string };
```

TypeScript assertion helper. **`uploadBundle`** calls it for you; you only need it if you build a thin wrapper that fails fast when **`OG_PRIVATE_KEY`** is unset.

```typescript
import { loadConfig, requireSigningConfig } from "@0gzk/sdk/node";

const config = loadConfig();
requireSigningConfig(config);
// config.privateKey is now typed as `string`.
```

Throws **`Error("Missing OG_PRIVATE_KEY. ...")`** when no key is found.

## Reading bundles

### `readBundleFromDir`

```typescript
function readBundleFromDir(bundleDir: string): Promise<BundleFiles>;
```

Reads **`metadata.json`**, parses it, then loads each file referenced in **`metadata.files`** (wasm/zkey as bytes, vkey as parsed JSON). If **`metadata.files.verifier`** is set and the file exists, the Solidity source is returned as **`verifier`**.

```typescript
import { readBundleFromDir } from "@0gzk/sdk/node";
import { generateProof } from "@0gzk/sdk";

const bundle = await readBundleFromDir("./circuit_bundle");
const proof = await generateProof(bundle, { x: 3, y: 5 });
```

Throws **`SyntaxError`** on malformed **`metadata.json`** and the usual **`ENOENT`** if any referenced file is missing.

### `fetchBundle`

```typescript
function fetchBundle(
  rootHash: string,
  config: Pick<StorageConfig, "indexerUrl">,
  outputDir?: string,
): Promise<BundleFiles>;
```

Downloads **`bundle.tar.gz`** from **0G Storage** by **`rootHash`**, extracts it into **`outputDir`** (or a fresh OS temp directory when omitted), and returns the same shape as **`readBundleFromDir`**.

```typescript
import { fetchBundle, loadConfig } from "@0gzk/sdk/node";

const config = loadConfig();

// Default: extract to an OS temp dir (good for one-shot scripts).
const bundle = await fetchBundle("0xabc...", { indexerUrl: config.indexerUrl });

// Or: pin to a cache directory so repeat fetches are essentially free.
const cached = await fetchBundle(
  "0xabc...",
  { indexerUrl: config.indexerUrl },
  `/tmp/0gzk/${"0xabc..."}`,
);
```

The third argument is plain "where do you want the tarball extracted"; **`fetchBundle`** does **not** check for an existing **`metadata.json`** there (the CLI handles caching at a higher level via **`OGZK_CACHE_DIR`**). Throws **`Error("0G download failed: ...")`** when the indexer rejects the request.

## Uploading bundles

### `UploadOptions`

```typescript
interface UploadOptions {
  timeoutMs?: number;                          // default: 5 * 60_000 (5 minutes)
  onProgress?: (progress: UploadProgress) => void;
}
```

**`timeoutMs`** is the wall-clock budget; non-finite values or **`<= 0`** disable the timer entirely (the upload still runs). Errors thrown inside **`onProgress`** are swallowed defensively so a buggy logger cannot tear down an upload.

### `uploadBundle`

```typescript
function uploadBundle(
  bundleDir: string,
  config: StorageConfig,
  options?: UploadOptions,
): Promise<UploadResult>;
```

Required bundle files (asserted before any network work): **`metadata.json`**, **`circuit.wasm`**, **`circuit_final.zkey`**, **`verification_key.json`**. Any other loose files (a **`verifier.sol`**, for example) are bundled too; an existing **`bundle.tar.gz`** at the top level is ignored.

The function packs a gzip tarball into an OS temp dir, computes the Merkle tree to derive **`rootHash`** locally, then submits via **`Indexer.upload`** (with a wallet built from **`config.privateKey`** and **`config.rpcUrl`**). It restores **`console.log`** / **`console.error`** in **`finally`**.

```typescript
import { uploadBundle, loadConfig, UploadTimeoutError } from "@0gzk/sdk/node";

const config = loadConfig({ network: "testnet" });

try {
  const result = await uploadBundle("./circuit_bundle", config, {
    timeoutMs: 10 * 60_000,
    onProgress: (p) => {
      console.log(`[${p.stage}] ${p.message}`);
      if (p.uploadedSegments && p.totalSegments) {
        const pct = ((p.uploadedSegments / p.totalSegments) * 100).toFixed(1);
        console.log(`  ${pct}%`);
      }
    },
  });

  console.log("rootHash:", result.rootHash);
  console.log("txHash:  ", result.txHash);
  console.log("txSeq:   ", result.txSeq);
} catch (err) {
  if (err instanceof UploadTimeoutError && err.rootHash) {
    console.warn("upload still finalizing; rootHash already known:", err.rootHash);
  } else {
    throw err;
  }
}
```

Throws:

- **`Error`** from **`requireSigningConfig`** when **`config.privateKey`** is unset.
- **`Error("Bundle directory does not exist: <path>")`**.
- **`Error("Bundle is missing required file: <name>")`** when any of the four required files is absent.
- **`UploadTimeoutError`** when **`timeoutMs`** elapses.
- **`Error("0G upload failed: ...")`** when the indexer returns an error.

### Progress flow

**`uploadBundle`** intercepts the 0G TS SDK's log lines to parse them into structured **`UploadProgress`** events, walking the stages below in order:

```mermaid
flowchart LR
  packing --> submitting --> streaming --> finalizing --> done
```

| Stage | Carries | Meaning |
| --- | --- | --- |
| **`packing`** | **`message`** | Building the tarball locally. |
| **`submitting`** | **`message`**, **`rootHash`** | Tarball ready; submitting the upload tx (rootHash is already computed). |
| **`streaming`** | **`uploadedSegments`**, **`totalSegments`**, **`rootHash`** | Bytes being sent to storage nodes. |
| **`finalizing`** | **`rootHash`** | Storage nodes are finalizing the file; this is the long part. |
| **`done`** | **`rootHash`**, **`finalized: true`** | All set. |

If **`timeoutMs`** elapses during **`streaming`** or **`finalizing`**, you still get an **`UploadTimeoutError`** with a populated **`rootHash`** in most cases. That hash is your recovery handle: the data is almost certainly on chain, you just stopped waiting. You can either re-call **`uploadBundle`** later (idempotent for the same content) or jump straight to **`CircuitRegistry.publishVersion`** (the CLI does this via **`0gzk registry register <rootHash> --bundle <dir>`**).

## What's not exported

**`packages/sdk/src/node/upload-internals.ts`** contains helpers like **`parseUploadLogLine`** and **`withTimeout`**. They are used by tests and are intentionally not re-exported. Treat them as private.
