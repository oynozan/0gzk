# Contracts

The Foundry package **`@0gzk/contracts`** (in the core monorepo) ships the **on-chain registry** and a minimal **verifier interface**. TypeScript clients use **`@0gzk/sdk/onchain`** with the same **`CircuitRegistry`** ABI; Solidity apps import or deploy these contracts as needed.

**`getRegistryContract(runner, address?, chainId)`** defaults `chainId` to **`8453`** (Base mainnet, the default network), so pass it explicitly whenever your runner points elsewhere — or pass the **`address`** explicitly if you deployed your own registry. The same table ships as [`registry-addresses.json`](https://github.com/0gzk/core/blob/main/packages/contracts/registry-addresses.json) in the contracts package and as `REGISTRY_ADDRESSES` in `@0gzk/sdk/onchain`. The registry occupies the same address on Base mainnet, Base Sepolia, and 0G mainnet (same deployer, nonce-0 CREATE).

The contract itself is **chain-agnostic and unchanged in 0.4.0** — the multi-chain and IPFS support rides entirely on the existing `metadataURI` field (see **[Networks & storage](/networks#bundle-uri-convention)**), so no redeploys were needed on 0G.

## `CircuitRegistry`

**Purpose:** An **index**, not a vault. It maps human-friendly circuit names to **immutable version records** that point at content-addressed storage (0G Storage or IPFS, distinguished by the record's `metadataURI`).

### Types you should know

- **`Version`**: **`rootHash`**, **`vkeyHash`**, **`verifier`**, **`publisher`**, **`publishedAt`**, **`metadataURI`**.
- **`Circuit`**: **`owner`** and the ordered list of version strings.

### Lifecycle (happy path)

1. **`createCircuit(name)`** claims a name (regex **`^[a-z0-9_-]{2,32}$`**).
2. Build and upload the bundle off-chain; obtain **`rootHash`**.
3. **`publishVersion(name, version, rootHash, vkeyHash, verifier, metadataURI)`**: owner pins that version forever.
4. Optionally **`setVerifier`** if the Groth16 verifier address was unknown at publish time.

### Consumer checklist

When you read a registry record:

1. Route on **`metadataURI`** (**`ipfs://...`** → IPFS gateway, otherwise **0G Storage** by **`rootHash`** — **`parseBundleRef`** in the SDK implements the rule) and fetch the tarball.
2. Recompute **`keccak256(canonical verification_key.json)`** and compare to **`vkeyHash`**.
3. Optionally call **`IGroth16Verifier.verifyProof`** on the stored **`verifier`** address.

The registry does not validate witnesses for you. It only says **where** the bundle lives and **which verification key** it commits to.

## `IGroth16Verifier`

Snarkjs-generated verifiers expose:

```solidity
function verifyProof(
    uint256[2] calldata _pA,
    uint256[2][2] calldata _pB,
    uint256[2] calldata _pC,
    uint256[] calldata _pubSignals
) external view returns (bool ok);
```

Cast your deployed verifier to this interface in Hardhat or Foundry for clearer types at call sites.

## Tooling

From the monorepo:

```bash
cd packages/contracts
forge build
forge test
```

### Deploy scripts

`package.json` carries one script per target: **`deploy:mainnet`**, **`deploy:galileo`**, **`deploy:base`**, **`deploy:base-sepolia`**, and **`deploy:base-sepolia:verify`** (the last also verifies the source on Basescan). Run them only with keys and RPC endpoints you control.

`Deploy.s.sol` reads the broadcaster key from **`DEPLOYER_PRIVATE_KEY`** first, falling back to the legacy **`OG_PRIVATE_KEY`**:

```bash
# 0G chains: the rpc_endpoints for `mainnet` / `galileo` expand ${OG_RPC_URL}.
export OG_RPC_URL=https://evmrpc.0g.ai
export OG_PRIVATE_KEY=0x<funded_key>
pnpm --filter @0gzk/contracts deploy:mainnet

# Base chains: fixed public RPCs in foundry.toml; Basescan verification needs
# a BASESCAN_API_KEY (wired via the [etherscan] section of foundry.toml).
export DEPLOYER_PRIVATE_KEY=0x<funded_base_key>
export BASESCAN_API_KEY=<key>            # only for the :verify variant
pnpm --filter @0gzk/contracts deploy:base-sepolia:verify
```

After a deploy, record the printed address in `registry-addresses.json` under the chain ID so the SDK and CLI can resolve it automatically.

**Source:** [`CircuitRegistry.sol`](https://github.com/0gzk/core/blob/main/packages/contracts/src/CircuitRegistry.sol), [`IGroth16Verifier.sol`](https://github.com/0gzk/core/blob/main/packages/contracts/src/IGroth16Verifier.sol).
