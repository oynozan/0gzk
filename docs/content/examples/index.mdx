# Examples

The **`examples/`** directory in [`0gzk/core`](https://github.com/0gzk/core) ships **five standalone projects**. Each installs **`@0gzk/sdk`** from npm and stays intentionally short (on roughly tens to ~100 lines of code).

The folder ships directly in the repo — a plain `git clone` brings it in.

## How to run any example

Most Node examples expect an **isolated install** (they are not part of the pnpm workspace):

```bash
cd examples/01-prove-in-node
pnpm install --frozen-lockfile --ignore-workspace
pnpm smoke
```

Swap **`01-prove-in-node`** for the folder you need. Each example page below lists its **entry files** and **what to look at**.
