# Getting started

This page assumes you are comfortable with a terminal and **Node.js 20+**.

## Install

**JavaScript library** (prover + validation; works in Node and modern browsers):

```bash
npm install @0gzk/sdk snarkjs
```

**CLI** (global `0gzk` binary):

```bash
npm install -g @0gzk/cli
```

You can use **pnpm** or **yarn** the same way.

## Environment variables

Operations that **upload** bundles, **register** on-chain, or **resolve** via the registry need configuration. The CLI and `@0gzk/sdk/node` read the same environment variables. The generic `OGZK_*` names are preferred since 0.4.0; the legacy `OG_*` names keep working.

Create a `.env` file (never commit real keys):

```bash
# base | base-sepolia | 0g-mainnet | 0g-testnet. Defaults to base (chain 8453).
# ("mainnet"/"testnet" still work as deprecated 0G aliases.)
# OGZK_NETWORK=base

# Required for gas-spending actions (0x + 64 hex chars).
OGZK_PRIVATE_KEY=0xYOUR_KEY_HERE

# Optional overrides (defaults work for most users):
# OGZK_RPC_URL=https://mainnet.base.org
# OGZK_IPFS_API_TOKEN=eyJ...       # pinning-service token, needed to publish via IPFS
# OGZK_STORAGE=0g                  # backend override (default: ipfs on Base, 0g on 0G chains)
# OG_INDEXER_URL=https://indexer-storage-turbo.0g.ai   # 0g backend only
```

- **Base (default):** nothing to set. The registry is on Base mainnet and bundles are pinned to **IPFS**, so publishing needs a pinning token (a Pinata-style JWT) plus Base ETH for the registration tx — no 0G wallet. Fetching and proving need neither.
- **Base Sepolia:** `OGZK_NETWORK=base-sepolia`, same IPFS backend, testnet ETH from any Base Sepolia faucet.
- **0G mainnet:** `OGZK_NETWORK=0g-mainnet` — this is the switch back from the Base default. Storage follows the chain family, so the backend returns to **0G Storage** and uploads need a funded 0G key.
- **0G testnet:** `OGZK_NETWORK=0g-testnet`, fund the address from the [0G faucet](https://faucet.0g.ai).

See **[Networks & storage](/networks)** for the full matrix.

Optional: point the CLI at a key without a file using `--key 0x…` on supported commands.

## Sanity checks

```bash
0gzk --version
```

```bash
node -e "import('@0gzk/sdk').then(m => console.log('ok', typeof m.generateProof))"
```
